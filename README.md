# Back of the Physics Test

A looping 10-second canvas animation of over-the-top textbook mechanics diagrams, under the caption *"The type of questions you see at the back of your Physics test after you already skipped 9 questions"*.

Everything is in `index.html` — no build step. Open it in a browser, or deploy the folder as a static site.

Controls: click or Space to pause, ← / → to step half a second.
